# image-prompt-manager

`image-prompt-manager` 是一个面向 Codex 的个人图片处理 Prompt 管理 Skill。它会把你真正想复用的修图、生图和图片风格方案保存在本机 SQLite 数据库中，并根据当前图片推荐合适方案、记录实际执行结果和反馈。

## 安装后为什么是空的

这是有意设计，不是安装失败。

- 每个人喜欢的图片风格不同，默认塞入固定方案会干扰个人推荐。
- 个人数据库保存在用户主目录的 `.image-prompt-manager`，不会跟随 Skill 上传到 GitHub。
- 浏览、推荐和安装不会虚增使用次数；只有真实执行成功后才记录一次使用。
- Skill、安装包与持续变化的个人数据彼此分离，升级 Skill 时不会覆盖你的库。

首次使用时，Codex 会检查库状态。如果库为空，它会提醒你怎样收集第一条图片处理 Prompt，而不是假装已经有可推荐的历史方案。

## 收集第一条 Prompt

### 方法一：直接粘贴 Prompt

把完整提示词和下面这句话一起发送给 Codex：

```text
把下面这段提示词收进图片库：
<在这里粘贴完整提示词>
```

Codex 会自动整理名称、分类、标签、适用场景、避用场景和优势。遇到高度重复的内容时，它会让你选择新增、合并、替换或取消，不会静默覆盖。

### 方法二：上传 Prompt 截图

附上包含提示词的清晰截图，然后发送：

```text
识别这张截图里的图片处理提示词，先核对完整文字，再收进图片库。
```

应先核对识别出的完整文字，尤其是密集表格、小字号、遮挡或多页内容；不能把无法确认的残缺文字当成完整 Prompt 收藏。

### 方法三：保存刚刚满意的效果

完成一次图片处理并确认效果满意后，可以说：

```text
把刚才这个效果收进图片库。
```

如果使用的是临时方案，Skill 会在你同意收藏后把它转为正式 `Pxxx`，并保留实际 Run、Prompt 快照和反馈。

## 第一次处理图片

打开一个新的 Codex 任务，附上一张图片并发送：

```text
处理一下这个图片
```

这句话只代表“分析图片并帮我挑方案”，不代表默认自然精修或立刻执行。正确流程是：

1. Codex 读取当前个人库并分析图片中可观察到的主体、背景、光线、色彩和用途。
2. Codex 展示带编号的现有 `Pxxx` 候选；库为空或覆盖不足时，展示一个临时 `Txxx` 方案。
3. Codex 停止并等待你回复编号、`Pxxx`、`Txxx` 或明确效果。
4. 你选定后，Codex 才调用图片工具并记录成功或失败。
5. 你可以评价结果；满意的临时方案可以再收藏进个人库。

选择前不会创建 Run、增加使用次数或直接修改图片。

## 常用说法

```text
处理一下这个照片
这张图怎么修会更好？
帮我挑一个适合这张图的效果
把下面这段提示词收进图片库：……
把刚才这个效果收进图片库
打开我的图片提示词库
看看 P004 以前的效果怎么样
刚才这个挺好
这个不太行，以后少推荐
```

## 是否内置示例 Prompt

当前版本不自动内置 Prompt。这样可以保证新用户的统计从真实选择开始，也避免把来源、授权或适用范围不明确的内容公开打包。

未来可以提供独立的“可选示例包”：用户主动选择后再导入，且示例包必须标明来源和许可。可选示例不会随安装自动写入数据库，也不会冒充用户偏好或历史使用记录。

## 数据保存位置

默认数据目录：

```text
~/.image-prompt-manager/
├─ prompts.db
├─ settings.json
├─ backups/
└─ exports/
```

所有确定性读写都通过 `scripts/library.py` 完成。不要手工编辑 SQLite 数据库，也不要把个人数据库、备份或导出文件提交到公开仓库。

## 安装

把下面整段内容发送给 Codex：

```text
请使用 skill-installer，把下面 GitHub 目录中的 image-prompt-manager Skill 安装到我的 Codex 默认 Skills 目录，并在安装后验证 SKILL.md、agents/openai.yaml、references、scripts 和 tests。如果目标目录已经存在，请先检查并告诉我，不要直接覆盖。请直接执行安装，不要只提供操作步骤：

https://github.com/jietian111/tj-toolbox/tree/main/skills/image-prompt-manager
```

安装完成后请打开一个新的 Codex 任务，使 Skill 列表重新加载。

## 技术边界

- Python 标准库与 SQLite，无云端数据库。
- Prompt 正文和核心执行策略的变化会创建不可变版本。
- 每次实际执行使用独立 Run，保存当时提交的 Prompt 快照。
- 失败 Run 不增加使用次数；自然反馈绑定最近一次成功 Run。
- 默认删除进入回收站；永久清理需要明确确认并自动备份。
- 不自动上传私人图片、数据库、备份或历史记录。
